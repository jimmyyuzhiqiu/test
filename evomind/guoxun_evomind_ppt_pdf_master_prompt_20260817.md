# 七、最重要的产品定位原则

整套材料必须讲清楚：

## 国巡机器人已经解决的是：

**工业现场智能化。**

机器人、传感器、AI视觉、检测设备、GINS等系统解决：

> “现场发生了什么？”

例如：

- 仪表读数是否异常
- 温度是否异常
- 是否有人员入侵
- 皮带是否跑偏
- 是否出现漏水
- 是否出现故障
- 是否出现危险状态

---

## EvoMind应该解决的是：

**围绕这些现场和项目数据，人和组织接下来如何完成知识工作。**

例如：

↓

↓

查项目资料

↓

查产品版本

↓

形成故障原因假设

↓

形成排障SOP

↓

工程师确认

↓

形成服务报告

↓

形成客户沟通材料

# 八、必须明确“不替代什么”

PPT中必须专门有一页：

# EvoMind不替代什么？

禁止把 EvoMind 描述成：

- 机器人实时运动控制系统
- PLC
- SCADA
- 实时安全联锁系统
- 机器视觉边缘推理系统
- GINS替代品
- 实时机器人导航控制系统
- 安全关键自动控制系统
- 未经人工审核即可直接下发机器人操作指令的系统

正确定位：

> **EvoMind位于企业知识工作、项目协同、文档、分析、Agent、Skill和组织能力沉淀层。**

如果未来能够通过 API / MCP / 数据接口连接 GINS 或其它业务系统：

只能写成：

> “未来可探索的集成方向”

不能写成：

> “目前已经完成集成。”

“你们一个新的项目进来以后，需要翻多少份历史材料？”

“一个现场问题，通常需要找几个人才能知道过去有没有发生过？”

“最有经验的技术人员的经验，目前沉淀在哪里？”

“同一类方案，每一个项目是不是还需要重新写一次？”

# 四十四、最终核心信息

整套材料最终必须让国巡员工理解四件事情：

## 第一

EvoMind不是另一个机器人系统。

## 第二

EvoMind帮助的是：

**机器人项目背后的知识工作。**

## 第三

不是每个人单独使用一个聊天机器人。

而是：

**企业知识 + Agent + Skill + 组织协同。**

## 第四

真正长期价值不是：

“今天AI帮我写了一份PPT。”

而是：

> 今天做过一次的优秀方法，明天整个组织还能继续使用。

# 四十五、最终价值表达

禁止大量使用：

- 降本增效
- 赋能
- AI革命
- 颠覆
- 全自动
- 替代员工

这些空泛表达。

改成具体业务价值：

- 减少重复查资料
- 缩短历史案例检索时间
- 提高技术方案初稿效率
- 减少项目资料遗漏
- 统一项目输出结构
- 加快新人熟悉业务
- 降低知识只存在个人电脑和个人经验中的风险
- 提高跨部门资料复用
- 让项目经验进入下一项目
- 让高频工作逐步形成标准Skill

如果没有真实测量数据：

禁止写：

“效率提升70%”

“成本下降50%”

等无依据数字。

# 四十六、设计质量检查

生成PPT和PDF前进行一次完整QA。

- 是否真正讲国巡？

- 一页一个核心结论
- 标题表达结论
- 正文不要堆字
- 流程图可读
- 16:9
- 投屏可读
- 页面风格统一

- 有页码
- 有章节导航
- Prompt可复制
- 操作路径明确
- 适合员工会后自行学习
